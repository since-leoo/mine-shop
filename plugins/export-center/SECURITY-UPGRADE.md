# 私有导出与撤权升级

新导出文件不再上传到公开附件存储。HTTP 服务和导出队列需共享 `EXPORT_PRIVATE_PATH`（默认 `storage/exports/private`），文件权限为 0600，目录创建权限为 0700；该目录和临时目录不得配置为 Nginx/CDN/应用静态资源目录。多节点部署必须挂载同一私有持久卷；HTTP 与队列进程使用能够读取 0600 文件的同一系统身份。

`GET /admin/export/tasks/{id}/download` 现在直接返回文件，需要登录令牌和 `export:task:download` 权限。前端已改为携带令牌获取 Blob，不再打开外部永久 URL；响应带 `Cache-Control: private, no-store`。文件路径不会出现在任务列表或详情中。

下载错误 JSON 不会保存成文件；401 复用令牌刷新/退出逻辑，403 展示拒绝原因。创建或重试入队失败会将任务标记为 `failed` 并记录完整服务端异常，业务调用端可显式重试，不会永久停留在等待状态。

生成开始与完成时记录/复核有效权限指纹；每次下载重新从数据库读取操作者，校验启停状态、角色、菜单权限、用户/岗位数据策略、有效部门及创建人集合。权限指纹改变时拒绝旧文件，用户须重新发起导出；生成途中变化则失败并清理临时文件。动态 CUSTOM_FUNC 无法提供稳定快照边界，普通用户使用此策略时拒绝持久化导出，须先配置明确的范围策略。超级管理员遵循现有全量策略。

旧任务中保存的 HTTP(S) 存储直链不再通过接口返回或下载，必须重新导出。**代码无法收回已经公开的历史对象或已下载到客户端的副本。** 上线前由存储管理员将旧导出对象转为私有或删除，并清除 CDN 缓存；本次代码修改没有操作生产存储。不要将旧 URL 迁移成新私有文件标识，它们没有生成时的权限证据。

文件过期清理及用户删除任务会删除对应私有文件；清理器不根据数据库中的任意绝对路径或外部 URL 删除其他文件。恢复备份时应同步恢复任务记录和私有文件。
