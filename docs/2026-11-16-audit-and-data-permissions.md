先前完成的 11 项问题修复继续保留；本次追加完成 DIY 定时发布、通知渠道、异常信息返回、导出撤权及 PHPStan 剩余诊断，并复核商品领域事件。权限依据用户确认的规则：**按后台创建人及其部门隔离已有归属的数据，其余单独列出**。

## 已接入的数据范围

业务表登记在 [OwnedTables.php](/Users/yy/PhpstormProjects/mine-shop/app/Infrastructure/Library/DataPermission/OwnedTables.php)。后台菜单权限校验通过后，请求启用数据范围；公开商城 API、支付回调、系统定时任务不套用后台用户范围。

| 功能 | 归属依据与覆盖 |

| 商品、品牌、分类 | 各自主表 created_by；SKU、属性、图库继承商品 |

| 后台系统消息、消息模板 | system_messages / message_templates.created_by |
| 后台用户、角色管理 | 管理控制器显式启用对应表范围，登录鉴权所需的用户/角色关系不全局过滤 |
| 异步导出 | 生成文件时重新加载任务操作者，按执行时策略过滤，完成/失败后恢复上下文；不凭队列进程身份读取全量数据 |

覆盖普通 Query Builder 查询、详情、统计、exists、cursor、update、delete，以及当前使用的别名、OR 条件和 union 分支。原查询条件整体与数据范围取交集。子表在新增/修改时还校验父记录是否可访问，根记录创建人由后台身份填充。

策略语义：SELF 为本人；部门策略通过创建人的部门、岗位所属部门、部门负责人关系确定；部门树包含下级部门；自定义部门只包含所选部门。空部门集合不放行，无策略默认本人，ALL 和超级管理员可访问全部。移除了会让策略变更不及时生效的旧共享缓存。

这不是任意 SQL 的通用隔离器。后续新增业务表必须登记；新增原生 SQL、复杂派生表或跨范围聚合必须单独审查，不能假定会自动获得同等保障。

旧记录的 created_by 为 NULL/0 时，本人/部门策略下不可见，ALL/超级管理员仍可处理。本轮没有将这些记录批量归给当前管理员，也未修改业务库数据。

## 本次追加修复

1. **DIY 定时发布。** 每分钟扫描到期记录，事务内锁记录与页面，重新检查操作人状态、发布菜单和当前数据权限；预约版本在继续编辑草稿时保持不变。重复调度仅发布一次，取消必须匹配页面，失败保留安全原因并结束预约，重新发布需重新预约。发布不改变页面启用状态，与手工发布一致。

2. **通知渠道。** 邮件通过已配置的 PHP MTA，短信与小程序复用现有插件，实时/设备推送通过带认证和幂等键的 HTTPS 网关。必须取得成功回执才记为 sent；站内收件记录才记为 delivered。去除重复异步代理，队列由 SendMessageJob 统一负责；拒绝入队不能标记成功，已成功渠道重试时跳过。配置见 [系统消息 README](/Users/yy/PhpstormProjects/mine-shop/plugins/system-message/README.md)。

3. **异常返回。** 生产环境隐藏数据库、SDK、类型错误与 JWT 密钥路径，完整异常留服务日志；保留明确的领域/参数错误及专门的业务、验证、鉴权响应。修正 Unauthorized handler 未停止传播，以及调试响应读取旧异常上下文的问题。明确的库存、限购、状态等业务拒绝改用领域异常，可恢复的基础设施错误仍保留重试语义，开发规范已同步。异步下单轮询只公开新版标记的安全文案，历史失败原文统一隐藏，处理中不返回内部诊断。短信验证码和供应商原始异常不再写入系统消息。

4. **导出撤权。** 文件移到非公开私有目录，前端使用鉴权 Blob 下载；生成前后与下载时比对操作人、角色/菜单状态、部门、岗位策略及有效创建人集合。权限变化后拒绝历史文件下载，生成中变化则删除新文件。队列拒收或异常会将任务标为失败，避免永久停留待处理。前端正确拒绝 JSON 错误 Blob，处理 401 刷新、并发失败与重试上限，不下载错误文件。拒绝旧公开 URL 和路径穿越；普通用户动态 CUSTOM_FUNC 策略不允许持久化导出。升级约束见 [SECURITY-UPGRADE.md](/Users/yy/PhpstormProjects/mine-shop/plugins/export-center/SECURITY-UPGRADE.md)。

5. **商品事件。** 不再创建第二条库存专用事件链。AppProductCommandService 只在业务事务里记录现有商品事件，并在提交后分发；库存初始化/增量/删除仍由 ProductSkuStockListener 处理，快照由 ProductSnapshotListener 处理。外层事务未提交时等待 outbox；监听器失败保留重试，重放不重复加库存、不覆盖预占、不复活已删除 SKU，也不改写供应链库存。AppTradeRecoveryService 的全部事件路由合并到单一 match，保留支付/取消多事件的顺序及未知事件重试记录。

6. **PHPStan 与检查中发现的实际缺陷。** app、config、全部插件 src 的 level 5 从 446 条降为 0；未新增笼统忽略规则，仅 xlswriter 的原生签名映射差异保留单行忽略，并用当前扩展实际生成文件验证格式。修正通用仓储/服务的类型与属性可见性、过期方法、ORM 关联与查询回调、供应链与微信接口调用、腾讯短信配置的 ?? 优先级等。优惠券统计改查领取表，API 领取与后台发放共用券行锁，避免最后一张券超发及个人限领竞态。
